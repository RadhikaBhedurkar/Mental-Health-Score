# 🧠 Mental Health Score Prediction

## 📌 Project Overview

**Mental Health Score Prediction** is a data-driven web application designed to analyze various lifestyle, behavioral, and personal factors and estimate a user's **mental health score**.

The project demonstrates how **Python, Machine Learning, Data Analysis, and Web Development** can be combined to build a practical predictive application.

---

## 🎯 Objectives

* Analyze factors that may be associated with mental health.
* Perform data cleaning and exploratory data analysis.
* Identify important patterns and relationships in the dataset.
* Train a machine learning model to predict a mental health score.
* Provide an easy-to-use web interface for entering information and viewing predictions.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/RadhikaBhedurkar/Mental-Health-Score.git
```

### 2. Navigate to the project folder

```bash
cd "Mental Health Score"
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```bash
venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in your browser

```text
http://127.0.0.1:5000/
```
